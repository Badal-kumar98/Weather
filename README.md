## Overview

This application delivers real-time meteorological metrics across global locations. Features include dynamic weather condition mapping, temperature conversions, humidity indicators, and wind speed calculations with instant visual feedback and smooth client-side routing.

## Tech Stack

- React 18
- Vite
- OpenWeatherMap REST API
- React Router (HashRouter for seamless GitHub Pages routing)
- React Hot Toast
- CSS3 (Responsive glassmorphism design)

## Features

- Live Search: Instant meteorological data fetching across any city worldwide.
- Dynamic Atmospheric Visuals: Real-time icon switching based on weather condition codes (clear, cloud, rain, drizzle, snow).
- Key Metrics Dashboard: Displays temperature in Celsius, humidity percentage, and wind velocity in m/s.
- Error Handling & Validation: Responsive toast notifications for invalid city inputs and network issues.
- Optimized Static Hosting: Fully configured for zero-downtime static deployment with relative base paths.
